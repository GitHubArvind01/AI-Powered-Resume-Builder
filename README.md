## 📌 Overview

**ResumeAI** is a full-stack AI-powered platform that helps users create, optimize, and export professional resumes using intelligent automation.

It provides:

* AI-generated resume content
* ATS score analysis
* Job matching
* Export to PDF/DOCX
* Real-time resume builder UI
